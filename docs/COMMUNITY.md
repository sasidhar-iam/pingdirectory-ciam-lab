# Help other CIAM engineers use the lab

Start with one scenario, run the local tests and explain the result in your own words. Report unclear steps and missing failure cases. Product-specific feedback is especially useful when it includes the tested server, JVM and SDK versions.

## Good contributions

- Reproduce a documented scenario in an authorized test environment and provide a redacted result.
- Add negative tests for an actual failure or ambiguity.
- Fix a command against a clearly stated product version.
- Improve setup instructions for a new reader.

## Sharing the work

Share a link to a specific scenario where community rules permit it. State whether it is a design, a local model or a tested integration. Include limitations and invite technical feedback. Do not post customer information or claim vendor endorsement, production deployment or compliance certification without evidence.

Repository topics can help relevant searches. The maintainer can set accurate topics through the repository About settings. Suggested topics include ciam, identity-access-management, ping-identity, oauth2, openid-connect and the specific product covered here. Only add topics that match the repository contents.

Avoid unsolicited bulk messages, duplicate promotional posts and requests for artificial stars or activity. Useful examples and reproducible evidence are the goal; reach is not guaranteed.
