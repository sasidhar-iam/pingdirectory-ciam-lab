# Contributing

Open an issue describing the problem and expected behaviour. Use sample data only. For a change, create a branch, add relevant positive and negative tests, run `npm test`, and open a pull request explaining the result. State which tests you could not run.

For vendor integrations, record the product, JVM and SDK versions. Do not describe a generic unit test as evidence of vendor compatibility. Only share code you have permission to publish; preserve attribution and describe your contribution accurately.

Contributions use the MIT License.
